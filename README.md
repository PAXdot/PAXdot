### 👋 About me

I'm a full-stack developer at **[Compass Solutions](https://compasssolutions.io)**, where I build and run software for real businesses, from the first database table to the production server.

- 🧩 **Business systems:** custom CRMs, invoicing, scheduling, inventory and reporting tools tailored to how each company actually works.
- 📱 **Mobile companions:** native Android apps in Kotlin that connect field teams to the same backend.
- 🤖 **Automation:** bots, scrapers and scheduled jobs that monitor, notify and remove repetitive work.
- 🌐 **Websites:** fast, multilingual marketing sites focused on clarity and conversion.
- 🖥️ **Infrastructure:** I deploy and maintain everything myself on Linux servers, with CI/CD, monitoring and backups.

Most of my work lives in private client repositories, so the contribution graph tells more of the story than the public repo list.

### 🚀 How I work

- **End to end:** I take products from idea to production and keep them running afterwards.
- **Built for real users:** admin panels, mobile apps and integrations designed around day-to-day operations.
- **Automate the boring parts:** if a task repeats, it becomes a script, a cron job or a bot.
- **Ship often:** small iterations, continuous deployment and monitoring in production.
